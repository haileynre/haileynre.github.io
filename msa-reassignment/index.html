How they were assigned

  1. Pulled the 803 Chris and Joe leads and the 213 recent signups with an empty MSA field.
  2. Sorted the combined 1,016 leads by Close lead id, so the order is stable and not based on name, book size, or who had them before.
  3. Walked that list in order and assigned Shemelia Freeman, Daisha Kincade, Mirisa Robles, Julia Warmus, then repeated. 1,016 divides by 4, so each person received 254.
  4. Wrote only the Member Success Advisor (MSA) user field on the lead. Before each write, the lead was read again. A Chris or Joe lead was skipped if it was no longer theirs. An empty lead was skipped if someone had already been assigned. None of those happened.
This evens this batch only. It does not balance the books they already had. Mirisa’s existing book was already the largest, so her full book is still the largest after adding 254.

“Empty” means the field was blank at the time of the update. Close search cannot show an advisor who was set and later cleared, so a lead in that situation would have been included with the 213.

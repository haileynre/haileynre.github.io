# Opt-outs to 76819

Public page for STOP-style replies to the Subto shortcode on November 13–16, 2026,
from 1:40pm through 11:59pm Mountain time. Each reply is tied to the 76819 text
sent to that person immediately before.

## Open it

https://haileynre.github.io/76819-optouts/

Or open `index.html` locally. One static page, no build, no login.

Phone numbers and the full wording of personal replies are not in this folder.
Reply text is stored as a keyword (`stop`, `don't text`, and the like). The
outbound texts are the Subto messages those replies followed.
